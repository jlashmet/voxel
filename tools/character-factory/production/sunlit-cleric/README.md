# Sunlit Cleric production prototype

The source reference in `front.jpg.b64/` is a compact automation copy derived from the project's Sunlit Cleric turnaround. The numbered chunks are concatenated and decoded by the dedicated GitHub Actions workflow before local TripoSR reconstruction.

The first production gate intentionally uses the front turnaround view so it can preserve source color on the Apple-Silicon TripoSR path while validating automatic reconstruction, canonical rigging, embedded gameplay clips, and preview rendering. The remaining turnaround views are reserved for the multiview geometry refinement pass once this baseline is stable.
