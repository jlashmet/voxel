# Plan

## Goal / acceptance
Ship one reusable stylized water renderer for still, flowing, and waterfall profiles through canonical voxel storage/extraction and `Hidden/VoxelEngine/WaterSurface`. Built-player evidence must visibly show distinct motion and a production-quality waterfall with coherent downward flow, turbulence/aeration, irregular breakup, lip/edge/base foam, and free mist/spray. No scene-local renderer/material fork; `.github/test-request.json` stays off `fixes/agent-9`.

## Selected fix / next gates
Add a production-shader raster regression that renders the same Cascade body with and without semantic side-edge topology: edge-tagged Cascade must lose localized silhouette coverage while still water with the same topology remains unchanged. Then use only existing `WaterEdgeFlag` semantics to apply descending-noise side erosion in the waterfall body clip; do not raise the global cutoff again, alter still/river depth behavior, add scene-specific shader policy, or change extraction/storage contracts. Re-run the edge regression and `WaterArenaDrawRegressionTests` on the exact new feature head, then the 60-second built showcase and direct near/wide/time-separated review. The hard triangular base-spray silhouette is a separately demonstrated visual defect; re-evaluate it after edge acceptance and isolate its geometry/raster cause before changing spray again.

A5 remains blocked: Kentridge is a real independent renderer consumer but current captures show no visible water. Prove `VoxelShowcase` plus another actual production scene with visible water; never substitute `WorldbuildingGalleryShowcase`.
