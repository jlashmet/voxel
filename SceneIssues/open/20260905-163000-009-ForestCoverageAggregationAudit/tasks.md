# R09 — Execution checklist

Budget: 30–45 minutes active work, excluding queued CI. Follow [plan.md](plan.md).

- [ ] Map production vegetation source, stable IDs, near/far selection, readiness and any aggregation consumer; distinguish unused implementation from wired behavior.
- [ ] Inspect available exact-player elevated/ground evidence and record actual distance bands, visible instance/batch counts and canopy gaps.
- [ ] Separate source density, representation quality, selection/handoff, culling and fog explanations; do not diagnose density from counts alone.
- [ ] Deliver the first missing production boundary, visual classification and smallest next experiment. Defer new canopy meshes, instancing/culling systems or density tuning.
- [ ] Record findings, artifact provenance and limitations; update the concise plan with material results and falsified hypotheses. A test failure may be the investigation result, never a successful validation claim.
- [ ] Review the issue-only diff and complete documentation checks. Close only if investigation acceptance is satisfied; otherwise retain the blocker in `open/`. Follow the canonical PR/merge workflow and verify the result on master.
