# Town concept-pack format

Each frozen-roster town folder is a directly consumable environment-art reference pack:

- `brief.md` — identity, provenance, architecture, palette, terrain/infrastructure and role mapping established before concept production.
- `concept-atlas.svg` — the town's shared authored visual vocabulary and six finished concept panels.
- `01-overall-elevated.svg`
- `02-exterior-signature.svg`
- `03-exterior-secondary.svg`
- `04-interior-signature.svg`
- `05-interior-secondary.svg`
- `06-street-public-space.svg`

The six numbered files are the canonical downstream entry points. Each resolves one semantic image role from the co-located atlas so future agents can reference exactly one concept without copying or drifting the town's visual vocabulary. Current in-engine town screenshots are not art-direction authority for these files.
