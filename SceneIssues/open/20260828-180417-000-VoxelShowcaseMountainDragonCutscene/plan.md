## Root cause and revision-8 topology
`experiment-010-switchback-core-gap-minimal-repro.md` isolated the third-failure cause: one X-axis ramp keeps a fixed Z footprint while the tapered core near face retreats about 69 voxels during each 46-voxel rise. `BoxEmitter.Ramp` inspection confirmed `ReverseRampBit` only reverses rise direction; it cannot make one X ramp follow Z. Therefore another offset-only fix was forbidden by the two-fix rule and structurally incapable of satisfying shell overlap at both ends.

Revision 8 keeps the deterministic tapered X-run contract and adds semantic shell-following subsegments. `MountainPathTierGeometry` records both shell-relative Z endpoints and deterministically subdivides a tier so each segment's shell retreat is less than the walking-lane overlap remaining after its exposed outer edge. Segment X/Y/Z endpoints are exact and shared by support authoring, headroom carving, path surface emission, and evidence waypoints. Both the baseline and semantic-material production catalogues consume the same segment contract; production can no longer silently retain the rejected single-ramp topology.

The regression now requires exposed-but-overlapping natural shell at both low and high ends of every tier and every segment, exact segment/tier connectivity, deterministic upper-run narrowing, shared evidence coordinates, and a lower support raster-cost proxy. Static calculation for the current authored layout is about 40 support frusta / 301M conservative proxy versus roughly 45 / 451M for the revision-6 control, well inside the 512-primitives-per-instance budget. Startup landmark provenance is revision 8, so older payloads cannot mask this realization.
