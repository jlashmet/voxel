# Plan — WorldBuilder Road Network Integration

## Acceptance
Promote Kentridge organic roads into a reusable WorldBuilder contract: semantic intent/provenance first, deterministic terrain-aware resolution, one continuous influence for voxel grading/surface transition/ecology, reusable keep-clearance, and a bounded physical representation. Kentridge is the proving consumer; the generic module must not depend on Kentridge. Final proof is the built `KentridgePlayableSlice` application with endpoint continuity, walkability, natural shoulders/vegetation recovery, and no chunk/LOD/runtime failure.

## Discrimination result
The representation gap is resolved in the branch. `Game.WorldBuilder.Api` owns reusable road profile/intent/resolution/influence/network data; Kentridge `SettlementPlan.Routes` and macro `TopDownWorldRouteSpec` hard connections author it. Physical lowering is one bounded `EmitTerrainCorridor` primitive per piece, not historical carve/core/ten-strip shoulders. `TerrainCorridorRasteriser` grades destructible terrain and persists the same 0..31 road influence used for presentation; Kentridge vegetation consumes that scalar.

Targeted CI `33281599556` (source `2e3574af`) executed seven road regressions and exposed two real defects. The `19 -> 26` shoulder increase came from per-sample edge hashes: Kentridge's ±2dm edge policy could change effective width by 4dm between adjacent samples. Aggregate overlap was not a sufficient explanation. Semantic and physical influence now evaluate the same deterministic 64dm bilinear world-space variation at the nearest centerline point, keeping decorative edge drift coherent across a shoulder while retaining profile-controlled irregularity. The vegetation failure was pre-existing on master: fixed non-residential tree coordinates were treated as immutable even though seeded organic buildings can occupy them. Those coordinates are now preferred anchors; clear anchors stay exact, blocked anchors use the same bounded deterministic <=120dm clearance search while preserving species/zone intent.

## Terrain flags
The generic resolver supports Blocked/Water/Reserved/Pass flags and profile crossing policy. Current production terrain/Kentridge/top-down route sources provide no authoritative water/reserved/barrier map, so adapters return `None` rather than fabricate crossings; deterministic fixture coverage proves the generic policy.

## Blast radius / cost
No per-frame road generation, road GameObjects, dense world masks, storage-width changes, or surface-vertex stride changes. Coherent edge variation adds only four integer corner hashes plus rounded interpolation per queried/rasterized road sample; it does not enlarge route data, primitive counts, or residency. Kentridge anchor relocation runs only during deterministic semantic vegetation planning and examines at most 48 nearby points per blocked authored anchor. Road work remains deterministic planning/catalogue generation; each bounded physical piece budgets one primitive under `FeatureBudget`. Final player evidence must still quantify generated definitions/primitives, build/runtime residency health, and visible streaming/LOD continuity.
