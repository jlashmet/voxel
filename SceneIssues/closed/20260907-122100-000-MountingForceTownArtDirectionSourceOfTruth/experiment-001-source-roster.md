# Experiment 001 — source roster discriminator

## Hypothesis
The original Mounting Force repository establishes the settlement identities and named places, but a later repository may supersede that roster.

## Action / source SHA
Pinned and inventoried `jlashmet/mounting-force` at `f37512e0175f46e14ad2d7aeb5ecea290af14a14`, then compared `jlashmet/MountingForce2` at `5e111d5a72e441824311b4a3a176f72e9c86f653`. Connected reference material was also searched for Cambridge and additional plausible town names.

## Result
The original project packages dedicated settlement/map groups for Kentridge, Hightown, Moordell, Rossdam, Orc Village/Orc-Town and Fairy Village, with town-specific named interiors/shops/houses. The later repository did not provide matching asset-path evidence that supersedes those settlement definitions. Cambridge was not recovered from either pinned historical repository.

## Verdict
Original-source identity + the coordinator's explicit Cambridge requirement is the supported model. Freeze the seven-settlement roster before concept generation. Cambridge's water-town requirement is coordinator-canonical; additional Cambridge art-direction anchors must remain labeled derived rather than historical.
