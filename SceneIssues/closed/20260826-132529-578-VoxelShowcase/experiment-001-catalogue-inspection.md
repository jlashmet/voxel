# Experiment 001 — catalogue inspection

**Hypothesis:** generated structures are empty because the shared generated-house realization does not author generic interior props.

**Action / source:** inspected the production `KentridgeSharedStructureVoxelCatalogue` / `KentridgeSharedHouseProgram` path at the pre-fix source state.

**Result:** generated roles emitted shell, openings, and roof; only the Pub had an interior counter. Town and plot dressing catalogues were exterior stages.

**Verdict:** confirmed. Add a deterministic interior-prop catalogue at the generated shared-structure composition boundary, leaving bespoke roles unchanged.
