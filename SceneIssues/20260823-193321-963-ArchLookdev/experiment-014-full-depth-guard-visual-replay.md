# Experiment 014 — full-depth guard visual replay

**Hypothesis** — Correcting the isolated early-layer coverage deficit removes the marked
staircase in the production arch.

**What was performed** — Rebuilt the production `ArchLookdev` player through
`tools/unity-run.sh` on the working tree based at `7e5b34d95`, then ran it for 25 seconds at the
saved 1637x1140 camera pose and 34-degree field of view. Evidence is
`verification-full-depth-guard-pose.png`, `verification-full-depth-guard-marked-region.png`, and
`verification-full-depth-guard-build.txt`.

**Result** — The hypothesis was disproven. The staircase remains visible behind the smooth
retained intrados in the same marked upper-left/crown region. The full-depth guard changes the
generated profile but does not materially change the reported edge.

**What was learned** — The two-primitive scalar fixture found a genuine coverage deficit but did
not reproduce the visible object's ownership faithfully. The staircase pixels are generated by a
different surface or depth boundary than the retained-profile-versus-backing crossing modeled by
that fixture. Visual isolation must identify the owning mesh before another production change.

**Next** — Run paired exact-camera diagnostic builds with retained profiles disabled and with the
composed backing removed/isolated. Use the smallest variant that retains the staircase as the
faithful bare-bones visual reproduction.
